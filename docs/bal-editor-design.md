## 1. 核心原则

**BAL（Business Action Language）是业务人员写规则的语言，不是 DRL。**



* 主视图永远是 BAL 自然语言，不是 DRL

* DRL 是编译产物，藏在 "高级 → 查看 DRL" 折叠面板里

* 业务分析师看到的是中文句子，开发者看到的才是 `when/then`

* 所有术语、字段、值都从 BOM 自动补全，不允许手写标识符



***

## 2. BAL 语法规范（中文版）

### 2.1 规则结构



```
规则 "规则名"

&#x20; 当

&#x20;   <条件行>

&#x20; 那么

&#x20;   <动作行>
```

### 2.2 条件行语法



```
\[量词] \[事实类型] 的 \[字段] \[比较符] \[固定值 | 业务字段]
```



* **量词**：存在 / 所有 / 没有（默认 "一个"）

* **事实类型**：业务术语名（如 "借款申请人"、"贷款申请"）

* **字段**：业务术语字段（如 "年龄"、"信用分"）

* **比较符**：等于 / 不等于 / 大于 / 小于 / 大于等于 / 小于等于 / 属于 / 不属于 / 包含 / 不包含

* **固定值**：字面量（数字 / 字符串 /true/false/ 日期 / 枚举值）

* **业务字段**：同一规则输入中的另一个业务字段。只能选择 input 方向、与左字段业务类型完全相同且不是左字段自身的字段。例如“温度 >= 最低温度”。

值区域使用“固定值 / 业务字段”分段切换。选择业务字段后，下拉项显示“事实类型 · 字段名”，候选项由 BOM 自动过滤；没有兼容字段时禁用业务字段模式。

多条件用 **并且 / 或者** 连接，支持括号分组。

### 2.3 动作行语法



```
设置 \[事实] 的 \[字段] 为 \[值]

添加 \[理由] \[文本]

移除 \[事实]

插入 \[新事实类型]
```

### 2.4 完整示例



```
规则 "申请人未成年拒绝"

&#x20; 当

&#x20;   一个 借款申请人 的 年龄 小于 18

&#x20; 那么

&#x20;   设置 贷款决定.批准 为 false

&#x20;   添加 理由 "申请人未成年"

&#x20;   设置 贷款决定.风险等级 为 "拒绝"
```



```
规则 "高风险贷款需要人工审核"

&#x20; 当

&#x20;   一个 借款申请人 的 信用分 小于 600

&#x20;   并且 一个 贷款申请 的 金额 大于 500000

&#x20; 那么

&#x20;   设置 贷款决定.需要人工审核 为 true

&#x20;   设置 贷款决定.风险等级 为 "高"
```

### 3.2 关键交互



* **每个条件 / 动作是一行卡片**，不是纯文本

* 每个下拉选择器都从 BOM 拉数据：


  * 事实类型下拉 → BOM 的 factTypes（借款申请人 / 贷款申请 / 贷款决定）

  * 字段下拉 → 选中事实类型的 fields

  * 比较符下拉 → 根据字段类型变化（数字有 >/<，字符串有 包含，枚举有 属于）

  * 值输入框 → 根据字段类型变化（数字用 number input，枚举用下拉，日期用 date picker，布尔用 true/false）

* **+ 添加条件**按钮 → 新行，默认 "并且" 连接

* **行尾删除按钮**（×）

* **拖拽排序**条件行（MVP 不做，先上下箭头）

* **BAL 预览**：在下方折叠区实时显示编译后的中文 BAL 文本

* **DRL 视图**：在 "高级" 折叠面板里，只读，显示编译后的 DRL

## 4. 和 BOM 的联动机制（核心）

### 4.1 数据结构

BOM（已有 `/api/projects/:id/bom`）：



```
{

&#x20; "factTypes": \[

&#x20;   {

&#x20;     "name": "Borrower",

&#x20;     "label": "借款申请人",

&#x20;     "fields": \[

&#x20;       {"name": "age", "label": "年龄", "type": "number"},

&#x20;       {"name": "creditScore", "label": "信用分", "type": "number"},

&#x20;       {"name": "yearlyIncome", "label": "年收入", "type": "bigdecimal"},

&#x20;       {"name": "delinquencies", "label": "逾期次数", "type": "number"}

&#x20;     ]

&#x20;   },

&#x20;   {

&#x20;     "name": "Loan",

&#x20;     "label": "贷款申请",

&#x20;     "fields": \[

&#x20;       {"name": "amount", "label": "金额", "type": "bigdecimal"},

&#x20;       {"name": "durationMonths", "label": "期限(月)", "type": "number"}

&#x20;     ]

&#x20;   },

&#x20;   {

&#x20;     "name": "LoanDecision",

&#x20;     "label": "贷款决定",

&#x20;     "fields": \[

&#x20;       {"name": "approved", "label": "批准", "type": "boolean"},

&#x20;       {"name": "riskLevel", "label": "风险等级", "type": "enum", "values": \["低","中","高","拒绝"]},

&#x20;       {"name": "reasons", "label": "理由", "type": "list\<string>"},

&#x20;       {"name": "needsManualReview", "label": "需要人工审核", "type": "boolean"}

&#x20;     ]

&#x20;   }

&#x20; ]

}
```

### 4.2 联动规则



| BOM 变化                | BAL 编辑器反应                                |
| --------------------- | ---------------------------------------- |
| 新增事实类型                | 事实类型下拉自动出现新选项                            |
| 新增字段                  | 选了该事实类型后，字段下拉出现新字段                       |
| 删除字段                  | 所有引用该字段的规则**标红警告**，不允许保存                 |
| 字段类型变更（number→string） | 引用该字段的规则值输入框类型变化，不匹配的值标红                 |
| 字段中文 label 修改         | BAL 里显示名自动更新（用户存的是 field.name，显示用 label） |
| 枚举值增减                 | 枚举字段的值下拉自动更新，被删的枚举值在规则里标红                |

### 4.3 术语渲染



* **业务术语**（事实类型名、字段名）：蓝色虚线下划线（`#0f62ff`，`border-bottom: 1px dashed`）

* **值**：灰底等宽（`background:#f0f0f0; font-family:monospace`）

* **操作符**（< > = 属于）：黑色加粗

* **连接词**（并且 / 或者 / 如果 / 那么）：灰色

* 点业务术语 → 跳到 BOM tab 对应字段

### 4.4 存储格式

规则的编辑态不是字符串，是**结构化 JSON**：



```
{

&#x20; "name": "申请人未成年拒绝",

&#x20; "salience": 0,

&#x20; "when": {

&#x20;   "combinator": "and",

&#x20;   "conditions": \[

&#x20;     {"factType": "Borrower", "field": "age", "operator": "<", "value": "18"},

&#x20;     {"factType": "ProcessControlInput", "field": "gasPct", "operator": ">=", "valueSource": "field", "valueField": "minPct", "value": ""}

&#x20;   ]

&#x20; },

&#x20; "then": {

&#x20;   "actions": \[

&#x20;     {"type": "set", "targetFact": "LoanDecision", "field": "approved", "value": false},

&#x20;     {"type": "addReason", "value": "申请人未成年"}

&#x20;   ]

&#x20; }

}
```

BAL 文本只是这个 JSON 的渲染形式，不是存储格式。这样 BOM 变更时能程序化分析影响。

`valueSource` 缺省或为 `literal` 时读取 `value`，保持旧规则兼容；为 `field` 时读取 `valueField`。右侧字段与左侧字段都计入 BOM 引用和变更影响分析。

扩展操作符继续使用结构化字段保存：

```
{"field":"customerAge","operator":"between","value":"18","valueEnd":"65"}
{"field":"customerType","operator":"in","value":"","values":["个人","企业"]}
```

数字/日期区间由双输入控件编辑，枚举属于/不属于由多选菜单编辑；字符串、日期和列表操作根据 BOM 类型自动切换控件，不允许业务人员手写 DRL。

## 5. 编译链路（BAL JSON → DRL）



```
BAL JSON (结构化)

&#x20; ↓ bal-to-drl.ts (前端或后端)

DRL 文本

&#x20; ↓ Drools KieSession

执行结果
```

编译示例：



```
{"factType":"Borrower","field":"age","operator":"<","value":"18"}
```

→



```
\$borrower : Borrower(age < 18)
```

同类型字段比较：

```
{"field":"gasPct","operator":">=","valueSource":"field","valueField":"minPct","value":""}
```

→

```
$input : RuleInput( gasPct >= minPct )
```

字段操作数直接生成字段标识符，不按字符串字面量加引号。后端在生成 DRL 前再次校验右侧字段存在、为 input、类型一致且不是自身。



```
{"type":"set","targetFact":"LoanDecision","field":"approved","value":false}
```

→



```
\$decision : LoanDecision()

then

&#x20; modify(\$decision) { setApproved(false) }
```

编译在后端做（Node.js 层），前端只负责编辑和预览。

## 6. 决策表的特殊处理

决策表不是 BAL 行编辑，是**网格**：



* 每行 = 一条规则

* 每列 = BOM 的一个字段

* 空单元格 = 通配

* 区间用 `600..700`，枚举用 `a,b,c`

* 命中策略在 Ruleset 配置里（COLLECT/FIRST/PRIORITY）

决策表也从 BOM 自动生成列头，BOM 删字段时整列标红。

## 7. 验收清单（codex 改完后逐项核对）



* [ ] 规则编辑器打开后，**默认显示结构化 BAL 行**，不是 DRL

* [ ] 事实类型下拉能列出 Borrower/Loan/LoanDecision（中文 label）

* [ ] 选了 Borrower 后，字段下拉列出 年龄 / 信用分 / 年收入 / 逾期次数

* [ ] 字段类型 number → 值输入框是数字框

* [ ] 字段类型 enum → 值是下拉（低 / 中 / 高 / 拒绝）

* [ ] 字段类型 boolean → 值是 true/false 下拉

* [ ] "如果 / 并且 / 或者 / 那么" 连接词灰色显示

* [ ] 业务术语蓝色虚线下划线

* [ ] 值灰底等宽

* [ ] 值区域可在“固定值 / 业务字段”之间切换

* [ ] 业务字段下拉只列出同类型 input 字段，且排除左字段自身

* [ ] `gasPct >= minPct` 以结构化 JSON 保存并生成不带引号的 DRL

* [ ] 数字/日期介于、日期早于/晚于可保存并通过 Drools 编译

* [ ] 字符串包含/不包含/开头/结尾/正则可保存并通过 Drools 编译

* [ ] 枚举属于/不属于使用结构化多选值

* [ ] 列表包含/不包含/长度比较可保存并通过 Drools 编译

* [ ] 右侧业务字段被删除或改为不同类型时，规则在资产列表标红警告

* [ ] 右上角 "DRL 只读" 按钮改成 "高级 ▾ → 查看 DRL"，默认折叠

* [ ] 删除 BOM 字段后，引用它的规则在资产列表标红警告

* [ ] 保存时 BAL JSON 结构化提交，不是字符串

## 8. 不在本期做



* BAL 自由文本输入（MVP 只用下拉 / 选择器，不让用户手打）

* 拖拽调整条件顺序（用上下箭头）

* BAL 语法智能提示（v2）

* 跨事实类型 join（`$b : Borrower(age>18) and Loan(borrowerId == $b.id)`）

* 函数调用（`length(name) > 3`）

* 全局变量 / 时间窗口
